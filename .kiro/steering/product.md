# 產品說明

## 這是什麼

Evidence-first 的加密貨幣市場研究 Agent。輸入幣種與研究問題，在時間預算內整合 11 類資料來源，
產出一份**每個結論都能點回原始來源**的研究報告。

支援幣種：BTC、ETH、SOL、BNB、XRP（輸入驗證會擋下其他輸入）。

## 核心設計原則（修改程式碼時必須維持）

1. **證據可追溯**：每個結論都要能回到 evidence ID 與來源 URL。不得讓模型自行捏造數據。
2. **立場由規則決定，不由模型決定**：偏多／中性／偏空來自證據訊號的加權計算
   （`_market_stance()`），不是 LLM 自由生成。同一批證據必須永遠得到同一個立場。
3. **主動提出反證**：系統從本次訊號中自動抽出反向的那一側，不是模型客套話。
4. **單一來源失敗不得中斷流程**：每個 adapter 獨立 try/except，失敗改用可靠度 0.20 的降級證據，
   並在執行記錄中標示。
5. **誠實優先於好看**：限制、樣本數不足、未驗證的路徑都要明說。回測頁開場就講樣本數不足。

## 產出物

- `report.md`：立場、事實、推論、反證、稽核、風險、來源
- `evidence.json`：每筆證據含 URL、取得時間、可靠度分數、追溯欄位
- `execution_log.json`：每步狀態、耗時、三階段預算使用、降級紀錄

## 明確的非目標

- 不是投資建議，不產生可執行的買賣訊號
- 不宣稱預測能力（回測樣本數為 1–3 筆／幣，不足以證明策略有效）
- 不追求資料來源數量最大化；差異化在可稽核性
